# nhl-api-ts

TypeScript SDK **and** command line tool for the NHL API and NHL EDGE stats.

This repository is a pnpm workspace:

| Package | Description |
| --- | --- |
| [`nhl-api-ts`](packages/nhl-api-ts) | The SDK and CLI, published to npm. Start with its [README](packages/nhl-api-ts/README.md). |
| [`api-types-infer`](packages/api-types-infer) | Private tooling that derives the SDK's response types from live API responses. Not published. |

```bash
npm install nhl-api-ts
```

See [CONTRIBUTING.md](CONTRIBUTING.md) to develop, and [AGENTS.md](AGENTS.md)
for repository conventions.
